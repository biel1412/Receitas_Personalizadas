# Receita Personalizada 🍲

Aplicativo de receitas para iPhone, dividido em **Café, Almoço, Lanche e Janta**.

- Cadastre receitas com **ingredientes**, **modo de preparo** e **foto** (opcional).
- Busque por nome ou ingrediente; edite e exclua quando quiser.
- Funciona **sem internet** depois de instalado.
- As receitas ficam salvas **no próprio aparelho**. Use o menu **⋯ → Salvar backup** de vez em quando.

## Como instalar no iPhone

1. Abra **https://biel1412.github.io/Receitas_Personalizadas/** no **Safari**.
2. Toque em **Compartilhar** (quadrado com a seta para cima).
3. Toque em **Adicionar à Tela de Início** → **Adicionar**.

Pronto: o ícone aparece na tela inicial e o app abre em tela cheia.

## Arquivos

| Arquivo | Para que serve |
|---|---|
| `index.html` | O aplicativo inteiro (telas, estilos e lógica) |
| `manifest.webmanifest` | Nome, cores e ícones do app instalado |
| `sw.js` | Guarda o app no aparelho para funcionar offline |
| `icons/` | Ícones da tela inicial |
